# ડાયલ બોર ગેજ સિમ્યુલેટર

ITI ફિટર, ટર્નર, મશીનિસ્ટ અને મિકેનિક મોટર વ્હીકલના તાલીમાર્થીઓ માટે સંપૂર્ણ ગુજરાતીમાં ઇન્ટરેક્ટિવ સિમ્યુલેટર. એક જ HTML ફાઇલ છે, ઇન્ટરનેટ વગર પણ ખુલે છે (ફોન્ટ માટે ઇન્ટરનેટ હોય તો વધુ સારું દેખાય).

## કઈ રીતે ખોલવું
- `index.html` ફાઇલ ડાઉનલોડ કરી કોઈ પણ બ્રાઉઝર (Chrome, Edge, Firefox)માં ખોલો.
- અથવા GitHub Pages ચાલુ કરો: **Settings → Pages → Branch** પસંદ કરો, પછી `.../dial-bore-gauge/` લિંક ખોલો.

## વિભાગો
1. **થીયરી** — વ્યાખ્યા, ઉપયોગ, કાર્ય સિદ્ધાંત, ટર્નિંગ પોઇન્ટ અને કોસાઇન ભૂલ, લઘુત્તમ માપ, ઓવાલિટી, ટેપર, ઘસારો, પ્રકાર, ભૂલોના સ્ત્રોત.
2. **ભાગો અને રચના** — નંબરવાળું ચિત્ર, 11 ભાગો અને તેમનું કાર્ય, અંદરની વેજ મિકેનિઝમ, ગેજ સેટની વિગત.
3. **સિમ્યુલેટર** — લાઇવ પ્રેક્ટિકલ:
   - જોબ પસંદ કરો (એન્જિન સિલિન્ડર, હાઇડ્રોલિક સિલિન્ડર, બેરિંગ હાઉસિંગ, પંપ બોડી)
   - સાચો એક્સ્ટેન્શન રોડ + વોશર પસંદ કરી ગેજ જોડો
   - સેટિંગ રીંગમાં ગેજ હલાવી ટર્નિંગ પોઇન્ટ પર ઝીરો કરો, બેઝલ લોક કરો
   - જોબમાં 3 ઊંડાઈ × 2 દિશા = 6 માપ લો
   - ઓવાલિટી/ટેપર ગણો, સ્વીકાર્ય/અસ્વીકાર્ય નિર્ણય લો અને 100માંથી ગુણ મેળવો
   - અભ્યાસ મોડ (મદદ પેનલ + ગ્રાફ) અને પરીક્ષા મોડ (મદદ વગર)
   - સતત 0–100 અથવા સંતુલિત 0–50–0 ડાયલ
4. **રીડિંગ પ્રેક્ટિસ** — અમર્યાદિત રેન્ડમ ડાયલ રીડિંગ પ્રશ્નો, તરત જવાબ અને સમજૂતી.
5. **ટેસ્ટિંગ પદ્ધતિ** — બોર તપાસના 10 પગલાં, ગણતરી સાથેનો ઉદાહરણ રિપોર્ટ, ગેજનું કેલિબ્રેશન, સાવચેતી, સામાન્ય ભૂલો.
6. **MCQ ટેસ્ટ** — 35 પ્રશ્નો, અભ્યાસ અને સમયબદ્ધ પરીક્ષા મોડ, ગ્રેડ, સમીક્ષા અને ખોટા પ્રશ્નો ફરી કરવાની સુવિધા.

## નિયંત્રણ
- ગેજ હલાવવા: કાપ-દ્રશ્ય પર ડાબે-જમણે ખેંચો, સ્લાઇડર ફેરવો, કીબોર્ડ ← → અથવા "આપોઆપ હલાવો".
- રિપોર્ટમાંની મર્યાદાઓ ઉદાહરણ માટે છે; વાસ્તવિક કામમાં ઉત્પાદકનું વર્કશોપ મેન્યુઅલ અનુસરો.
